
## How to run locally
1. Clone the repository:
   git clone https://github.com/kumkum001313-cell/kumkum001313.git

2. Open the site directly in your browser:
   - Double-click `index.html`, or
   - From the repository folder, run:
     python -m http.server 8000
     then open http://localhost:8000 in your browser.

3. Alternately, use a static server:
   - npx http-server
   - Or the "Live Server" extension in VS Code.

No build steps or dependencies are required.

## How to customize
- Edit content (name, bio, education, projects, contact) inside `index.html`.
- Update styles in `style.css` for color, layout, or typography changes.
- Modify form behavior or add integrations (e.g., an API or serverless function) in `script.js`.

## Deployment
- Deploy to Netlify, GitHub Pages, or any static host by pointing it at the repository or uploading the build files.
- Netlify: drag-and-drop the repository files or connect the GitHub repo for continuous deploys.
